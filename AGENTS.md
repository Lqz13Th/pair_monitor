# pair_monitor

- The collector only reads: public market data, account endpoints and the bot's data dir over rsync. It never signs
  anything but Lighter auth tokens for reads.
- `src/spread.rs` holds the signal arithmetic (premium, midline, deviation, episodes). Keep it in step with pair_arb's
  `signal.rs`; it is pure and unit-tested.
- Live sampling and the backfill share `market::Sampler`, so historical and live rows are computed the same way.
- Dashboards are generated by `grafana/build_dashboards.py`; edit the Python, not the JSON, then run it with
  `--check`.
- Secrets stay out of the repo: `config/local.toml` and `data/` are ignored, and the Lighter key comes from
  `LIGHTER_KEY_FILE` at run time.
